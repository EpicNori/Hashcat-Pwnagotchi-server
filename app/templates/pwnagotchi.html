Pwnagotchi Integration

Automate your handshake uploads directly from your Pwnagotchi to this server.

1. Install the Plugin

On Jayofelony Pwnagotchi, add this repository URL to your existing custom plugin repos, update the plugin index, and install the plugin with the built-in plugin manager.

main.custom_plugin_repos = [
    "https://github.com/EpicNori/Hashcat-Pwnagotchi-server/archive/refs/heads/main.zip"
]
sudo pwnagotchi plugins update
sudo pwnagotchi plugins install pwnagotchi_hashcat_wpa

The plugin installs enabled with default settings, so the next step is only replacing the placeholder server URL.

2. Open the Plugin Setup Page

Open the Pwnagotchi plugins page, click pwnagotchi_hashcat_wpa, replace 100.x.x.x with your server IP or hostname, then press Save config and Test connection.

If you prefer editing /etc/pwnagotchi/config.toml by hand, the plugin creates this default block for you on first start:

main.plugins.pwnagotchi_hashcat_wpa.enabled = true
main.plugins.pwnagotchi_hashcat_wpa.url = "http://100.x.x.x:9111"
main.plugins.pwnagotchi_hashcat_wpa.username = "admin"
main.plugins.pwnagotchi_hashcat_wpa.password = "changeme"

Use a URL that matches the path you want: local LAN, Tailscale, or an HTTPS Cloudflare Tunnel hostname.

3. Choose Your Remote Access Path

Tailscale: If you want private mobile uploads without exposing your server to the public internet, Tailscale remains the easiest VPN path.

curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up

Run that on both the hashcat server and the Pwnagotchi, then put the server's Tailscale IP into the plugin setup page like http://100.x.x.x:9111.

Cloudflare Tunnel: If you want the Pwnagotchi to upload over normal tethered internet without running a VPN client, publish the server through Cloudflare Tunnel and use an HTTPS hostname in the plugin.

cloudflared tunnel login
cloudflared tunnel create hashcat-wpa
cloudflared tunnel route dns hashcat-wpa upload.example.com
cloudflared tunnel run hashcat-wpa

Point the plugin to a hostname like https://upload.example.com. Keep Tailscale if you prefer a fully private network path. The system supports both so the operator can choose.

4. How it Works

Once configured and restarted (systemctl restart pwnagotchi), your Pwnagotchi will:

  • Scan for new handshakes in the background.
  • Automatically upload them whenever it has an internet connection.
  • You can check the User Profile on this dashboard to see real-time updates!

Quick Tips

Bluetooth Tethering: Tether your phone to your Pwnagotchi to enable instant uploads while mobile.

Tailscale: Use the same tailnet on both devices and point the plugin to the server's 100.x.x.x address.

Cloudflare Tunnel: Use an HTTPS hostname if you want internet-based uploads without a VPN client on the Pwnagotchi.

Multiple Users: You can create separate operator accounts for each of your Pwnagotchi units.
