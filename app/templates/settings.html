How do these limits work?
  • Dual GPU Support: You can now specify individual intensity for up to 2 GPUs.
    • 0%: Disables the device completely.
    • 1-100%: Enables the device and sets the global workload profile (-w) based on the highest setting.
  • Workload Mapping (-w):
    • 1-25%: Low usage (Desktop remains responsive)
    • 26-50%: Medium (Default balanced mode)
    • 51-75%: High (Intense cracking)
    • 76-100%: Nightmare (Maximum heat/Full utilization)
  • Cracking Strategy:
    • Rainbow: Normal mode checks the ESSID-specific WPA PMK cache before any wordlist or brute-force work.
    • Wordlists: Wordlists run only when selected for a task.
    • Brute Force: Leaving the wordlist choice on brute force continues into staged WPA masks if rainbow does not find the key: numbers, letters, letters+numbers, then printable+special up to 8, then 10, 12, 14, and onward to 63.
  • Spare Device Queue: When enabled, the first active handshake uses the default devices. Other queued handshakes may run on remaining enabled devices instead of waiting.
